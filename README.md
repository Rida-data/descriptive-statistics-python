# Descriptive Statistics with Python

## About This Project
This is my first Python project as a BSc Statistics and Mathematics student. It demonstrates basic descriptive statistics using Python.

## Objectives
- Calculate the mean, median, and mode.
- Practice working with lists in Python.
- Understand how Python can support statistical analysis.
- Calculate the range of a dataset.
- Calculate sample variance.
- Calculate sample standard deviation.

## Dataset
The example dataset is:

`[10, 20, 20, 30, 40]`

## Results

| Statistic | Result |
|---|---:|
| Mean | 24.0 |
| Median | 20 |
| Mode | 20 |
| Range | 30 |
| Sample Variance | 130.0 |
| Sample Standard Deviation | 11.4018 |

## Tools Used
- Python 3.13
- IDLE

## How to Run
1. Download `mean_calculator.py` from this repository.
2. Open it using Python IDLE.
3. Select **Run → Run Module**.

## Sample Output
```text
Numbers: [10, 20, 20, 30, 40]
Mean: 24.0
Median: 20
Mode: 20
```

## What I Learned
- Using Python lists to store data.
- Calculating descriptive statistics.
- Using Python's built-in `sum()` and `len()` functions.
- Importing the `mode()` function from the `statistics` module.
- Using `max()` and `min()` to calculate the range.
- Using `statistics.variance()` to calculate sample variance.
- Using `statistics.stdev()` to calculate sample standard deviation.
